A program that writes one original sentence to /output/entry.txt: the excuse a house cat gives in the five seconds after knocking a glass off the table — the glass was empty, squatting in the cat's sunbeam, and contributing nothing to the household, so the cat liquidated it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
